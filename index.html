How to play

Move all 52 cards to the four foundations, each built up by suit from Ace to King.

In the eight columns, cards stack in descending rank with alternating colours. The four free cells each hold one card of any kind.

Tap a card to pick it up (with any ordered run below it), then tap where it should go. Tap the same card again to send it to the best spot automatically. You can also drag.

You can move a run of cards at once as long as you have enough free cells and empty columns to have done it one card at a time.

Deals are numbered exactly like Microsoft FreeCell, so deal #11982 is still impossible.
